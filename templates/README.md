# Templates

This folder holds the **FilmScriptWriter** starter template used when:

- The app is opened for the first time (or no previous file can be restored)
- You choose **File → New**

## Files

| File | Description |
|------|-------------|
| `FilmScriptWriter-Starter.fountain` | Full starter with Fountain + outline examples |

## Important

When you work from this template and **Save** or **Save As**, your screenplay is written to a **new** path. The starter file itself is protected and is re-copied into `Documents/FilmScriptWriter/templates/` if missing, so it stays available as a starting point.
